
Kenyan Low-Resource Language Dataset
====================================

Language Pairs:
1. Kidawida ↔ Swahili
2. Kalenjin ↔ Swahili
3. Dholuo ↔ Swahili

Purpose:
This dataset is used for Federated Learning experiments
under non-IID data settings for low-resource language
representation learning.

Dataset Structure:
- kidawida_swahili.csv
- kalenjin_swahili.csv
- dholuo_swahili.csv

Columns:
- source_language
- target_language
- source_text
- target_text

Original Source:
https://huggingface.co/datasets/thinkKenya/kenyan-low-resource-language-data
